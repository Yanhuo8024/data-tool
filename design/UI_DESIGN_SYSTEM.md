# data.tool 全新 UI 设计系统 — 深色科技金融风

> 版本 v1.0 · 设计目标：专业感 + 科技感 · 主色：电光蓝 `#3b82f6`
> 配套可预览原型：`design/dashboard-prototype.html`（双击即可在浏览器查看）

---

## 1. 设计理念

- **专业感**：冷静的深色底、克制的留白、清晰的层级、统一圆角与对齐，像 Bloomberg / TradingView / Linear 的专业工具。
- **科技感**：电光蓝主色 + 青色点缀、微光边框、环境光晕、细网格背景、实时数据流与脉冲指示。
- **数据优先**：数字与代码统一使用等宽字体（JetBrains Mono），强化"分析平台"的专业气质。
- **一致性**：所有视觉由设计令牌（Design Tokens）驱动，杜绝散落硬编码，保证跨页面、跨主题一致。

## 2. 设计令牌（Design Tokens）

### 2.1 颜色

| 类别 | Token | 深色值 | 用途 |
|---|---|---|---|
| 背景 | `--bg-base` | `#070b12` | 页面底色 |
| 背景 | `--bg-surface` | `#0d1320` | 卡片 / 侧边栏 |
| 背景 | `--bg-surface-2` | `#111a2b` | 次级表面 / 图标底 |
| 背景 | `--bg-elevated` | `#0f1626` | 浮层 |
| 边框 | `--border-subtle` | `rgba(255,255,255,.06)` | 默认分隔 |
| 边框 | `--border-strong` | `rgba(120,170,255,.20)` | 强调分隔 |
| 边框 | `--border-accent` | `rgba(59,130,246,.55)` | 激活描边 |
| 文本 | `--text-hi` | `#e8eefc` | 主标题 / 关键值 |
| 文本 | `--text-mid` | `#9fb0cc` | 正文 |
| 文本 | `--text-lo` | `#5f7290` | 辅助 / 占位 |
| 主色 | `--accent` | `#3b82f6` | 主操作 / 激活 |
| 主色 | `--accent-hi` | `#60a5fa` | 高亮主色 |
| 点缀 | `--cyan` | `#22d3ee` | 青色点缀 / 渐变终点 |
| 语义 | `--pos / --neg / --warn` | `#34d399 / #f87171 / #fbbf24` | 成功 / 失败 / 警告 |

> 浅色主题（`[data-theme="light"]`）已定义，可一键切换：底色 `#eef1f6`、表面 `#fff`、文本反转为深色，其余语义色不变。

### 2.2 字体

- **UI 字体**：`Inter`（优先）→ `system-ui` → `PingFang SC` / `Microsoft YaHei` 兜底
- **数据 / 代码字体**：`JetBrains Mono` → `ui-monospace` → `Consolas` 兜底
- 字号阶梯（px）：12 / 13 / 14 / 15 / 18 / 24 / 27
- 字重：400（正文）、500（标签）、600（数值/小标题）、700（大标题）
- 行高：正文 1.5，标题 1.1–1.2

### 2.3 间距（4px 基准）

`--s1:4` `--s2:8` `--s3:12` `--s4:16` `--s5:20` `--s6:24` `--s8:32` `--s10:40` `--s12:48` `--s16:64`

### 2.4 圆角 / 阴影 / 微光

- 圆角：`--r-sm:6` `--r-md:10` `--r-lg:14` `--r-xl:20`
- 卡片阴影：`inset 高光 + 外投影 0 8px 30px rgba(0,0,0,.4)`
- 激活微光：`0 0 0 1px 主色, 0 8px 26px 主色光晕`
- 主色光晕：`--accent-glow: rgba(59,130,246,.45)`

### 2.5 布局变量

- `--sidebar-w: 268px`（折叠态 76px）
- `--topbar-h: 60px`

## 3. 组件库

### 3.1 按钮 Button
| 变体 | 样式 | 场景 |
|---|---|---|
| `.btn-primary` | 电光蓝渐变 + 微光阴影 | 最高优先级主操作 |
| `.btn-secondary` | 表面色底 + 描边 | 次级操作 |
| `.btn-ghost` | 透明底 + 细描边 | 低调 / 工具操作 |
| `disabled` | 透明度 .45 + 禁手型 | 不可用 |

- 高度 36–38px，圆角 `--r-md`，hover 上移 1px + 光晕增强。

### 3.2 卡片 Card
- 表面底色 + 1px 细边框 + 卡片阴影。
- 头部：标题（含线性图标）+ 右侧操作（分段控件 / 按钮 / LIVE 标签）。
- KPI 卡：左上图标圆底、大号等宽数值、环比 delta（绿涨红跌）、右下 sparkline。

### 3.3 导航 Navigation（侧边栏）
- 分组标题（大写 + 字距 + 低饱和），组内 `.nbtn` 图标 + 文字。
- 激活态：电光蓝左边条 + 文字高亮 + 微光描边 + 主色图标。
- 可折叠至 76px（仅图标），平滑过渡。

### 3.4 表格 Table
- 表头：大写低饱和、底部强分隔、可排序（hover 提亮）。
- 行：hover 高亮、状态徽章、等宽字体呈现关键数值。

### 3.5 状态徽章 Badge
`ok`（绿）/ `run`（蓝）/ `warn`（琥珀）/ `err`（红），圆角胶囊 + 前导圆点。

### 3.6 输入 Input
- 表面深色底 + 细边框，focus 时主色描边 + 微光。

### 3.7 进度 Progress
- 7px 圆角轨道 + 主色→青色渐变填充 + 光晕。

### 3.8 开关 Toggle
- 42×24 圆角，开启态主色 + 滑块右移（可点击切换演示）。

### 3.9 分段控件 Segmented
- 表面底 + 内嵌按钮，选中态主色填充 + 微光，用于时间范围 / 视图模式互斥单选。

| 断点 | 行为 |
|---|---|
| `>1100px` | 4 列 KPI、主图 1.9:1 双列 |
| `≤1100px` | KPI 2 列、主区单列堆叠 |
| `≤720px` | 侧边栏抽屉化（translateX）、隐藏搜索、KPI 单列、内容内缩 |

## 5. 可访问性（WCAG AA）

- **对比度**：文本 `#e8eefc` / `#9fb0cc` 在 `#0d1320` 上对比度均 ≥ 4.5:1。
- **键盘**：所有交互元素可 Tab 聚焦，`:focus-visible` 提供清晰焦点环。
- **焦点管理**：搜索框支持 `⌘K / Ctrl+K` 聚焦。
- **动效偏好**：`@media (prefers-reduced-motion: reduce)` 关闭所有动画与过渡。
- **触控目标**：按钮 / 导航项 ≥ 36px，满足移动端 44px 友好下限。

## 6. 开发者交接

1. **令牌落地**：将原型的 `:root` 令牌迁移为 CSS 变量文件（或 Tailwind 主题配置），全站引用，禁止散落色值。
2. **图标体系**：原型内置 20+ 线性 SVG symbol（`#i-*`），可直接复用，或替换为 Iconify / Lucide 等图标库，保持 1.5px 描边风格统一。
3. **主题切换**：原型已演示 `data-theme` 切换；接入时持久化到 `localStorage`（现有项目已有主题切换能力，可平滑替换）。
4. **骨架改造路径**：
   - 用 `.app` 网格壳替换现有"顶部平铺导航 + 主区"结构；
   - 侧边栏分组直接映射现有模块分组（智能流程 / AI提效 / 金融数据层…）；
   - 各 tab 模板（`templates/tabs/*`）沿用现有业务逻辑，仅替换外层容器与组件类名。
5. **下一步建议**：在原型基础上补充空状态、加载骨架屏、错误态规范，并产出 Figma / 设计 token JSON 交付。
