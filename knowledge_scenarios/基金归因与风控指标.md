# 基金归因与风控指标（场景知识）

## 信息比率 IR
- **公式**：(组合收益-基准收益) / 跟踪误差（active return 的波动）。
- **解读**：衡量"每单位主动风险换来的超额收益"，IR>0.5 较好，IR>0.75 优秀（长期）。
- **误区**：与夏普不同，IR 用基准锚定；单期高 IR 无意义，需长周期。

## 特雷诺比率 Treynor
- **公式**：(Rp - Rf) / Beta
- **解读**：每单位系统性风险的超额收益；只惩罚 β，不看非系统性风险。
- **适用**：已充分分散的组合与 CAPM 视角。

## Alpha / Beta 分解
- **定义**：回归 Rp - Rf = α + β(Rm - Rf) + ε。
- **Alpha**：超额收益（选股能力，需显著且可持续）；**Beta**：市场敏感性。
- **误区**：高α可能源于风格暴露/数据挖掘；样本过短 α 不可靠。

## 净值归因
- 把组合收益拆成：资产配置贡献 + 选券贡献 + 择时贡献。
- 常用 Brinson 归因；需基准与真实持仓，纯净值难做细粒度归因。

## 评分卡风控（KS / AUC / PSI 解读边界）
- **KS**：坏好样本累计分布最大差距，评估排序能力；>0.3 有区分度。
- **AUC**：排序概率，0.5=随机，>0.7 有区分度，>0.8 较强。
- **PSI**：样本(客群)分布在时间上的稳定性；<0.1 稳定，0.1~0.25 需关注，>0.25 明显漂移。
- **解读边界**：KS/AUC 好≠实际风控好（只是排序，忽略绝对水平）；PSI 高需查客群结构。
- **评分卡分数刻度**：一般设好/坏比 odds=1:1 或 1:x 对应某一基准分，每增加 ods=2 分或自定义 PDO；分越高违约概率越低。
