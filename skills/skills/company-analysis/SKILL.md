# 公司全方位分析

当用户请求对一家公司进行分析、生成公司分析报告，或给出公司名/股票代码并希望了解其基本面时，按本技能工作。

## 工作流程

### 第1步：识别公司
- 从用户消息中提取公司名（中文名/英文名）或股票代码（6位A股 / HK+4位港股）。
- 可识别的常见标的见内置映射表（贵州茅台/腾讯/宁德时代等）。
- 若无法识别，询问用户提供代码或全名。

### 第2步：调用全维度分析
调用后端真实数据分析接口 `POST /api/company-analysis，body={"company": "公司名或代码"}`，一次性获取结构化报告，覆盖 8 大章节：
1. **公司概况**：名称、行业、总市值、总股本、上市时间
2. **财务分析**：营收、净利润、营收/净利同比、EPS、ROE、杜邦拆解（净利率×周转×权益乘数）
3. **市场表现**：当前股价、PE、PB、毛利率、净利率、资产负债率、52周最高/最低
4. **DCF 绝对估值**：每股内在价值 vs 现价、偏差、结论
5. **相对估值**：可比公司 PE/PB/ROE 对比 + 行业中位数与高估/低估结论
6. **最新新闻与舆情**：近期个股新闻标题、时间、来源
7. **竞争对手对比**：同行业可比公司
8. **SWOT 分析 + 风险提示**：基于真实财务/市场数据的规则化判定

### 第3步：生成 Word 报告（可选）
- 若用户要求"下载/导出/生成 Word/文档"，调用 `POST /api/company-analysis，body={"company":"...","download":true}` 返回 .docx 文件供下载。

### 第4步：向用户呈现结果
- 若拿到结构化 JSON：用清晰的分节整理成可读报告，财务与估值用表格展示，突出结论（DCF结论、相对估值结论、主要风险）。
- 所有数字**必须以接口返回的真实数据为准，严禁编造**；数据缺失的字段明确标注"暂缺"。
- 分析结束后附投资合规免责声明。
