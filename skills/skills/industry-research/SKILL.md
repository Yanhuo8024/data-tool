# 行业全景研究

当用户请求对某个行业进行全景/深度研究（行业报告、市场规模、产业链、竞争格局、行业趋势、机会风险等）时，按本技能执行。目标：产出**结构完整、基于真实与可核验信息、覆盖六维**的行业研究报告，并最终回应用户。

## 工作流程

### 第1步：明确研究范围
- 从用户消息提取**行业名称**、**地域/市场范围**（如 A 股/中国/全球/港股）、**时间范围**（如近3年/2026年）。
- 若行业不明确，先确认行业名，再继续。
- 确定是否只做部分维度（用户只问竞争格局就只做竞争格局+必要的背景，不强行扩成六维全景）。

### 第2步：联网调研真实信息
对每个研究维度，先用 `web_search` 工具搜索权威来源（新闻、行业报告摘要、上市公司公告、政策原文），再用 Agent 已有金融数据工具（stock_screening / industry板卡 / company_analysis 等）取数。**核心原则：关键数字必须来自 web_search 结果或金融数据接口，不得编造；标注来源链接。**

六维调研要点：
1. **宏观与政策环境**：web_search 行业相关政策、监管、补贴、宏观周期对行业的影响。
2. **市场规模**：web_search 行业市场规模/增速/渗透率，给出量级与口径（注明数据来源年份）。
3. **产业链**：上游原材料/设备 → 中游制造/集成 → 下游应用/终端；识别关键瓶颈、卡脖子环节。
4. **竞争格局**：集中度（CR/TOP 玩家）、主要公司、市占率排序、竞争壁垒。
5. **重点企业**：对 2-4 家代表企业用 `company_analysis` 或股票数据工具取真实财务/估值，对比其规模、盈利、差异。
6. **趋势、机会与风险**：基于以上，提炼技术/政策/需求趋势，机会点与风险点（政策、技术迭代、竞争加剧、周期等）。

### 第3步：撰写结构化报告
整理为 Markdown 报告，覆盖（按需取舍章节）：
- **行业概览**：定义、规模、所处阶段（导入/成长/成熟/衰退）+ 总体判断
- **市场规模**：量级、增速、空间
- **产业链与关键瓶颈**
- **竞争格局**：表格对比主要玩家
- **重点企业**：表格对比，关键财务/估值
- **宏观与政策环境**
- **趋势、机会与风险**
- **结论与展望**

写作要求：
- 每个关键数字后标注来源（如 `[数据来源：XX/年份]`），沿用 web_search 返回的链接。
- 优先用表格呈现多对象对比。
- 若某维度网络信息不足，明确说明"该维度公开数据有限"，不编造。
- 语言专业、深入、有观点（该行业到底景气与否、竞争是否激烈、处于什么周期），避免空泛罗列。

### 第4步：导出 Word（可选）
- 若用户要求"下载/导出/Word/文档"，调用后端报告导出能力（/api/report/export-docx 或类似端点）生成 .docx 供下载。

### 第5步：回应用户
- 用 Markdown 输出精简版报告（管理摘要：研究范围+总体判断+按优先级组织的发现+机会/风险/成立条件+观察信号）。
- 末尾给出完整报告的可下载方式（Word）。
- 附合规免责：基于公开数据与行业信息，仅供参考，不构成投资建议。

## 关键约束
- **用工具取真实数据**：市场规模、公司财务、政策等关键事实必须来自 web_search / 金融工具，绝不臆造。
- **来源可追溯**：关键数字标注来源与年份；不确定时如实说明。
- **不强行六维**：用户指定维度时聚焦，不滥扩。
- 涉及具体上市公司估值/投资判断时，附"仅供参考，不构成投资建议"。
