      工作流接入 · Workflow API
      跟踪 data.tool 的 AI 助手 · 每次运行自动回放
      一条命令即可把你的工作流渲染到画布：AWV.load(spec)。也可以贴 JSON 后点「应用 Spec」，或直接把 .json 文件拖到页面上。

      URL 参数直挂（无需写代码）
      ?src=https://…/my-flow.json 从远端拉取 Spec · ?spec={…} 内联 URL 编码 JSON · &auto=1 载入后自动播放 · &live=<run_id>&api=http://127.0.0.1:8788 直连实时接口。

      你自己的 Agent 已经在本地某个端口上跑着（比如 127.0.0.1:5000）？ 不需要改造它的协议 —— 只要它有一个能返回「当前运行状态」的端点，这里就能把返回值实时映射到画布。 填端口 → 探测 → 点一行填入路径 → 连接。
      预设 自动跟随该端口最近一次真实运行 —— 读的是它的 /api/assistant/traces，无需改造服务
      主机:端口
      状态端点路径
      轮询间隔 ms
      未连接
      端点返回什么形式都能认。节点字段名可以是 nodes / agents / steps / tasks， 对象或数组皆可；连线是 edges / links； 指标是 stats / metrics / summary； 日志是 logs / events。
      节点名不必和 Spec 一致：先按 id / 名称匹配，剩下的按顺序对位。 状态词也做了归一化 —— running / 进行中 / 60 → 运行中， success / 已完成 / 100 → 完成， failed / 失败 → 失败， pending / 等待 / 0 → 未开始。

      REST 端点（默认 http://127.0.0.1:8788）

      GET/托管可视化器页面；/?run=<id> 自动载入该 run 的 Spec 并跟随实时事件
      GET/api/health健康检查，返回版本与 run 数量
      POST/api/workflow注册工作流 Spec（请求体即 Spec JSON），返回 run_id、url
      POST/api/runs/{id}/event推送单个事件（节点状态 / 连线状态 / 日志 / 评分）
      POST/api/runs/{id}/events批量推送：{"events":[…]}
      GET/api/runs/{id}/events?since=N&wait=1增量拉取事件（wait=1 长轮询最多 25s），返回 seq 与事件数组
      POST/api/runs/{id}/stats更新汇总指标：seconds / tokens / score / chip / note
      POST/api/runs/{id}/reset清空该 run 的运行时状态（保留 Spec）
      GET/api/runs列出全部 run

      事件字段（全部可选，只覆盖出现的字段）

      node节点 id
      stateactive / done / fail / idle
      status节点下方状态文字，如 完成 · 5,820 tok
      statusKindrun / ok / bad，决定状态文字配色
      edge + edgeMode连线 id + live / done / back / off
      actor + log写入 Run Log：actor · log
      score / seconds / tokens / chip直接改写底部统计栏
      kindreset 表示清空运行态，done 表示整体结束

      Python 调用（SDK 已随附）

      from agent_flow_client import FlowReporter

r = FlowReporter("http://127.0.0.1:8788")
run_id = r.create(spec)                    # 注册工作流，返回 run_id
r.node("collect", "active", status="多源检索中…", log="启动 12 个数据源")
r.edge("e1", "live")
r.node("collect", "done", status="完成 · 5,820 tok")
r.node("review", "fail", status="未通过 · 74.5", score=74.5)
r.edge("e8", "back")
r.stats(seconds=43.7, tokens=26940)
r.finish(score=92.6)                       # 结束并打印可打开的 URL
print(r.url)

  -H "Content-Type: application/json" \
  -d '{"node":"collect","state":"active","status":"多源检索中…","actor":"信息采集","log":"启动检索"}'

      页面内 JS API

      AWV.load(spec)载入 spec 对象或 JSON 字符串并渲染
      AWV.loadUrl(url)拉取远端 JSON 后渲染
      AWV.spec()返回当前 spec（可导出复用）
      AWV.run() / AWV.reset()播放 / 重置
      AWV.connect({api, runId})连接实时接口并开始跟随
      AWV.push(event)直接把一个事件应用到画布（不经过服务端）
      AWV.on(type, cb)订阅 load/run/event/done
