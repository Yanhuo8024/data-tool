💡 脚本怎么用 API Key
请求头带 X-API-Key 即可调用：知识库 / Agent 任务 / 定时任务 / 仪表盘数据接口
curl 示例（拉取大盘数据 / 知识库列表）：
# 大盘指数（公开接口，带 Key 可计入配额）
curl -H "X-API-Key: 你的_KEY" http://127.0.0.1:5000/api/dashboard/index-quote
# 知识库列表
curl -H "X-API-Key: 你的_KEY" http://127.0.0.1:5000/api/knowledge
Python 示例（提交 Agent 任务）：
import requests
r = requests.post(
    "http://127.0.0.1:5000/api/agent/tasks",
    headers={"X-API-Key": "你的_KEY"},
    json={"description": "分析上证指数近期走势"}
)
print(r.json())
