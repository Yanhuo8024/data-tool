故障排查手册

症状 → 原因 → 自助排查路径 · 覆盖 AI 助手 / 数据库 / 服务 / 数据等高频问题
提示：输入关键词后自动过滤；点击「展开排查步骤」查看完整路径。
🤖 AI 助手不返回结果
高发
可能原因：LLM 配置未生效 / Ollama 未启动 / API Key 缺失或过期 / 网络不通
① 检查「AI 助手」配置：模型是否选择（日日新 GLM-5.2 / DeepSeek-V4-Flash / Ollama 本地模型）；
② 若用 Ollama：确认已手动运行 ollama serve（网站启动不会自动拉起），并执行 ollama list 确认模型已拉取；
③ 若用日日新（sensenova）：Key 存于服务端加密凭据库 .secure/credentials.enc（非 .env）。可执行 python -c "from secure_config import credentials_diagnostic; print(credentials_diagnostic())" 自查；若提示 backend_ok: False，说明当前解释器缺 cryptography（pip install cryptography）；
④ 测试连通：AI 助手配置页「测试连接」；或访问 /api/llm/test 看返回；
⑤ 查看服务日志（start.bat 窗口 / logs/）是否有 LLM 相关报错。
🗄️ 数据库连接失败
高发
可能原因：驱动未安装 / 凭证错误 / 主机端口不通 / 防火墙 / 只读护栏拦截
① 先点「测试连接」看具体报错：No module named 'pymysql' → 执行 pip install pymysql（PG 用 psycopg2、ClickHouse 用 clickhouse_connect）；
② 核对主机/端口/库名/用户名/密码（凭证加密存储，改密码需重新填写）；
③ 本机用 netstat -ano | grep 端口 确认数据库在监听；防火墙放行端口；
④ SQLite 连接：database 填 .db 文件绝对路径；
⑤ 若查询被拦：提示"只允许只读查询 / 禁止多语句 / 危险函数"→ 属安全护栏（sql_guard）拦截，属预期行为，改写 SQL 即可。
🖥️ 页面空白 / 功能不显示
可能原因：浏览器缓存旧 JS / Service Worker 缓存 / 前端版本未更新
① 按 Ctrl+F5 强制刷新（清缓存重载）；
② 若仍异常：DevTools（F12）→ Application → Service Workers → Unregister（注销旧 SW）；
③ 确认后端已重启（改过代码后必须重启，见下方"服务启动失败"）；
④ 页面顶部若出现「检测到新版本」提示条，点击刷新。
🚀 服务启动失败 / 闪退
可能原因：端口被占用 / 依赖缺失 / Python 路径不对 / 残留双实例
① 端口占用：netstat -ano | grep 5000 找到 PID 后 taskkill /PID xxx /F 清理残留实例；
② 依赖缺失：pip install -r requirements.txt（或按报错补装）；
③ 启动用 start.bat（waitress 生产模式）或 python run_server.py；不要用 python app.py（那是开发模式）；
④ 看控制台首屏报错（UTF-8 已启用，中文可读）。
📄 数据文件打不开 / 乱码 / 上传失败
可能原因：编码不兼容 / 格式不支持 / 文件过大 / 安全校验拦截
① CSV 乱码：优先 utf-8-sig，系统会自动尝试 gbk/gb18030；仍乱码则用 Excel 另存为 UTF-8 CSV；
② 支持格式：csv / xlsx / xls / json / txt；超大文件（>100MB）会自动抽样前 10 万行；
③ 上传被拒：检查文件是否含脚本宏/危险内容（validate_upload_file 安全校验，属预期拦截）。
📊 图表不显示 / 中文乱码
可能原因：matplotlib 中文字体缺失 / CDN 加载失败 / 图片路径缓存
① 中文方块：确认系统装有微软雅黑/黑体（matplotlib 已自动注册 Windows 字体）；
② 图表空白：F12 Console 看是否有 JS 报错；网络异常时 ECharts/Plotly CDN 可能加载失败，刷新重试；
③ 图片类图表检查 output/charts/ 下是否生成。
⏰ 定时任务不执行
可能原因：调度器未启动 / EMBED_SCHEDULER=0 但 worker 未运行 / cron 格式错误 / 任务停用
① 默认模式（EMBED_SCHEDULER=1）调度器随主服务内嵌启动，日志应有 [Scheduler] 定时任务调度器已启动；
② 若设置了 EMBED_SCHEDULER=0：必须同时运行 python run_worker.py，否则调度不执行；
③ 检查任务是否「启用」、cron 表达式是否合法（如 0 9 * * *）；
④ 查看执行历史（定时任务页）确认 last_status 与报错。
🃏 评分卡建模报错
可能原因：目标变量不是 0/1 / 样本太少 / 特征全缺失 / 分箱不收敛
① 目标列必须为 0/1 二分类（违约=1）；
② 样本量建议 ≥ 1000（好/坏样本均 ≥ 100）；
③ 特征列需为数值型且缺失率不宜过高；
④ 分箱报"无法单调"时改用非单调分箱或减少最大箱数。
🕷️ 爬取无结果
可能原因：页面结构变化 / 反爬 / 选择器不匹配 / 网络被墙
① 用浏览器 F12 核对选择器是否仍匹配当前页面结构；
② 部分站点有反爬（需 UA/延迟），可减少并发页数；
③ 金融类数据优先用「金融数据」内置接口（akshare 等），稳定性更高。
📋 通用排查三板斧
1. 看日志：启动窗口（start.bat）滚动输出即服务日志；结构化日志在 logs/ 目录；
2. 看接口：F12 → Network，找到失败的请求看状态码与响应 error 字段（多数接口会返回可读错误信息）；
3. 重启生效：改过后端代码必须重启（start.bat 重新运行）；改过前端 JS 后 Ctrl+F5。
