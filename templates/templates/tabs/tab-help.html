1 快速开始 3 步上手 · 快捷键速记
📦 系统环境：Windows · Python 3.11 · Flask + pandas + sklearn + matplotlib + Plotly
🚀 启动方式：双击 start.bat → 浏览器访问 http://127.0.0.1:5000
📊 演示/示例数据：位于「存储」标签页可选，常用：
　· 长期护理保险面板（长期护理保险试点是否缓解了家庭消费结构降级…xlsx · 373行×18列 · 31省份 2013–2024 · DID 政策评估演示）
　· finance_ml_final_project_data.csv（1200行×27列 · 金融风控/信贷违约预测）
　· Sales Analysis Report 1.xlsx（7991行×12列 · 销售订单分析）

⚡ 3 步上手：
1️⃣ 选择文件 → 在顶栏下拉框选择数据文件（所有标签页共享同一文件）→ 点击「📈 分析」查看概览
2️⃣ 绘制图表 → 选择 X 轴（如"省份"）和 Y 轴（如"生存型消费占比"） → 选择图表类型 → 生成
3️⃣ 深入分析 → 切换「相关性」「分组统计」「机器学习」等标签页进一步挖掘
💡 快捷键：Ctrl+Shift+1~9 切换标签页 | Ctrl+K 全局搜索 | Ctrl+Shift+A AI助手 | Ctrl+Enter 执行操作 | Ctrl+Shift+L 切换主题 | ? 查看所有快捷键
🔑 数据源配置：tushare token 已内置（secure_config），baostock 免费免配置，akshare 依赖网络连通性
🧭 看 AI 到底干了什么：AI 助手每次问答的轨迹都会画到「🧭 Agent 流程」画布上——节点状态、连线流动、逐步耗时、失败原因一目了然（多 Agent 并行时会看到多个节点同时亮起）
🔧 卡住了怎么办：先到「🔧 排查」手册按症状对号入座（9 类高频故障、含可直接复制的排查命令），再按看日志 → 看接口 → 重启生效三板斧走
2 演示数据集说明
数据文件：长期护理保险试点是否缓解了家庭消费结构降级基于双重差分法的实证评估1.xlsx
数据主题：中国 31 省份长期护理保险（长护险）试点与家庭消费结构 — DID 政策评估演示面板
时间范围：2013 — 2024 年（12 年）
数据量：373 行 × 18 列（含「试点/处理组」「政策前后」等 DID 变量）

列名及含义：
省份31 个省级行政区（北京、上海…）
年份2013-2024
生存型消费占比（%）食品、住房等基本消费占比
发展型消费占比（%）教育、医疗、交通等消费占比
享受型消费占比（%）文化娱乐、旅游等消费占比
失能老人占比（%）完全/部分失能老人比例
老年慢性病患病率（%）高血压、糖尿病等慢性病患病率
居民人均可支配收入单位：元
平均家庭户规模每户人口数
城镇化率城镇人口占比
大专及以上人口占比（%）高等教育人口比例
城镇调查失业率城镇登记失业率
农村就业率农村劳动力就业率
人均地区生产总值人均 GDP
DID 专属变量：除上表消费/人口/经济列外，本面板还含「是否试点（处理组）」「政策前后（时点）」等双重差分标识列，用于「treat×post」交互项回归——可直接在「DID 计量」标签页选择省份/年份/处理组与政策时点运行政策评估。
其他示例：finance_ml_final_project_data.csv（1200×27，信贷客户风控/违约预测）、Sales Analysis Report 1.xlsx（7991×12，销售订单明细分析）。

3.1 数据概览
仪表盘 / 快捷入口 / 文件列表
默认进入的首页式仪表盘（tab-overview）：
  • 4 张 KPI 卡片：数据文件数、已保存模型数、功能标签页数、API 接口数，实时统计
  • 快捷入口：一键跳转到智能流程 / 自然语言查数 / 数据分析 / 机器学习 / 报告等核心模块
  • 数据文件列表：展示「存储」中的当前文件，便于快速定位

用途：首次进入先建立全局认知，再进入具体功能标签页。
📥
3.2 数据接入
上传 / 存储 / 爬取 / 数据库直连
上传 tab：支持 CSV、Excel (.xlsx/.xls)、TXT、PDF 文件上传。
  • 自动检测文件编码（UTF-8 / GBK）
  • 文件安全校验（类型 + 大小 + 魔数检查）
  • 上传后自动生成 CSV 备用文件

存储 tab：管理已上传和生成的数据文件。
  • 查看文件列表及大小、删除 / 下载
  • 数据血缘快照（Git 风格）：创建快照 → 一键回滚

爬取 tab：网页数据采集，输入 URL → 自动提取表格数据；动态页面需配置 Selenium。

数据库直连 tab（🔗）：连接 MySQL / PostgreSQL / ClickHouse / SQLite。
  • 密码加密存储（接口永不回传明文）
  • 自然语言生成 SQL，只读执行（见 3.17 NLQ 与 3.26 安全中心）

使用示例：点击「上传」→ 选择本地 Excel → 文件出现在「存储」→ 各分析模块自动识别
🧹
3.3 数据清洗
9 种清洗操作 · 支持撤销
9 种清洗操作：
去重删除重复行，保留首次出现
缺失值填充均值 / 中位数 / 众数 / 前值填充
异常值剔除sigma 倍数法（1σ / 2σ / 3σ）
文本清洗去空格/特殊字符/HTML标签
分类编码Label / One-Hot 编码
日期标准化统一日期格式
批量替换正则表达式替换
条件过滤按条件筛选行
缺失热力图可视化缺失值分布

操作步骤：点击「清洗」→ 选文件 → 初始化 → 选操作设参数执行 → 保存（结果存为 cleaned_data.csv）。支持撤销：每步有日志，可一键撤回。
📈
3.4 数据分析
描述统计 / 相关性 / 分组
描述性统计：均值、标准差、最小/25%/50%/75%/最大值、偏度、峰度、中位数，自动生成结论。

相关性分析：数值列两两 Pearson 相关系数，生成热力图矩阵。

分组统计：按任意列（如"省份"）分组查看统计量。

示例：描述性统计看消费结构概况 → 相关性分析看收入与消费 r 值 → 分组统计按省份比较差异。
📊
3.5 智能图表
自定义绘图 / Plotly 交互
支持类型：柱状图 / 折线图 / 散点图 / 直方图 / 箱线图；X、Y 轴均可多选列。
两种模式：静态图 (PNG, matplotlib，适合嵌入报告) / 交互图 (Plotly，缩放/悬停/下载)。

智能优化：
  • 分类变量自动处理，避免类型转换错误
  • 标签自动旋转：≤5 不旋转，6-12 个 30°，>20 个 60°
  • 长标签自动切换水平条形图

示例：X=省份，Y=生存型消费占比，柱状图 → 31 省对比（自动横向、标签旋转）。
🔢
3.6 表格工具
JOIN / 公式 / 透视表 / 抽样
多表 JOIN：左/右/内/外连接，按公共列合并
公式计算：12 种金融/统计公式：同比(YoY)、环比(MoM)、滚动平均、Z-score、波动率等
透视表：按行列汇总，支持 sum/mean/count 等聚合
交叉表：分类变量频数统计
数据抽样：随机 / 分层 / 时间分段抽样

示例：公式=YoY 列=人均地区生产总值 算同比增长；行=省份 列=年份 值=生存型消费占比 做透视。
🔍
3.7 A股筛选器
PE / ROE / 市值 / 行业 / 涨跌幅
功能：按市盈率 PE、最低 ROE、市值、市净率 PB、股价、最低涨跌幅、行业关键词 多条件筛选全部 A 股（约 5500 只，首次加载 10-20 秒）。

操作：填写条件（留空=不限）→「开始筛选」→ 结果表格展示 →「导出 CSV」。

⚠️ 提示：结果不构成投资建议，投资有风险，入市需谨慎。该能力与「3.13 金融分析」中的股票筛选同源，此处为独立标签页入口。
⏱
3.8 时序分析
分解 / ADF / ARIMA / Prophet
7 种时序操作：
日期特征提取年/月/日/星期/季度/是否周末
重采样日→周→月→季→年聚合
Prophet 预测自动处理节假日/趋势
滚动窗口移动平均/标准差/求和
时序分解趋势+季节性+残差
ADF 检验平稳性检验，自动差分
ARIMA/SARIMA自回归移动平均，自动选参

示例：选年份为日期列、消费占比为数值列 → 时序分解看趋势/季节 → Prophet 预测未来 3 年。
🔬
3.9 假设检验
11 种统计检验
支持的检验：t检验（独立/配对/单样本）、卡方检验、ANOVA 方差分析、Mann-Whitney U、Shapiro-Wilk 正态性、Kolmogorov-Smirnov、Levene 方差齐性、Welch's t-test 等（均已接入后端 API）。

操作步骤：选文件 → 选检验类型 → 选比较列 →「运行检验」→ 看 p 值/统计量/结论 → 可生成图表。

示例：比较东部与西部省份生存型消费占比差异 → 独立 t 检验。
🧠
3.10 机器学习
训练 / 预测 / 特征工程
算法：回归（Linear/Ridge/Lasso/RF/GBDT/SVR/XGBoost）、分类（Logistic/RF/SVM/KNN）、聚类（KMeans/DBSCAN/层次）。

流程：选文件 → 选 y 与 X → 选任务/算法 → 调测试集比例 → 训练 → 看 MSE/R²/特征重要性 → 模型存为 .pkl。

特征工程：自动标准化+多项式+交互特征；特征筛选 3 选 1：F 检验/斯皮尔曼秩相关（对非线性单调与异常值更稳健）/互信息。

预测：加载模型 → 输入新数据 → 一键预测。机器学习页另含「特征相关性(Spearman)」卡片，对导入数据做秩相关矩阵分析。
🃏
3.11 信用评分卡
分箱 / WOE-IV / 评分刻度 / PSI
用途：金融风控信用评分建模，将违约概率转成易读分数。

流程：① 选文件（目标列 0/1，1=违约）→ ② 特征分箱（等距/等频/卡方），算 WOE 与 IV（IV>0.1 有效）→ ③ 逻辑回归 → ④ 评分刻度（基准分/ODDS/PDO）→ ⑤ 评估 AUC/KS（AUC>0.7 良好）、PSI（<0.1 稳定）。

示例：用 output/credit_*.csv 训练 → 看分箱表、IV 排名、KS 曲线、PSI 报告。

分词 / 情感 / 关键词 / 词云
功能（依赖 jieba 分词）：

  • 情感分析：正 / 负 / 中性判定
  • TF-IDF 关键词：提取文本关键术语
  • 词云：可视化高频词
  • RAG 知识库：结合知识库做领域问答

示例：粘贴研报/评论文本 → 分词统计看高频词 → 情感分析看整体情绪 → TF-IDF 提取关键词 → 词云呈现。

3.13 金融分析
数据 / 可视化 / 建模 / 回测 / 五因子
数据获取（金融数据 tab）：
  • akshare：A股/港股/美股/ETF/期货/外汇/龙虎榜/涨停板
  • tushare：日/周/月K线、资金流向、十大股东（需 token）
  • baostock：免费无限频、无需 token——K线（前/后/不复权）、证券列表、沪深300/上证50/中证500 成分、四大财务报表、分红、行业、交易日历、ST 状态

金融可视化 tab：K线/MA/MACD/RSI/布林带/成交量/OBV/CCI/ATR；高级交互图（资金流向/筹码分布/热力图/收益曲线/最大回撤）；多股对比；框选 K 线联动过滤。

金融建模 tab：
  • CAPM：Alpha / Beta / Sharpe 比率
  • Fama-French 五因子：MKT/SMB/HML/RMW/CMA，季度末截面分组，输出因子收益统计与累计曲线（baostock，30 只×1 年约 1-2 分钟）
  • 策略回测：MA 金叉死叉 / MACD + 胜率·回撤·收益
  • 预测模型对比：7 种模型 MAE/MSE/RMSE/R²；模型保存复用

示例：取 600519 茅台日K → K线+MACD → 回测 MA 交叉 → 看夏普与最大回撤。
📈
3.14 固定收益分析
久期 / 凸性 / 曲线 / 利差 / 压力测试
单债计算器：输入票息 / YTM / 期限 / 付息频率 → 净价、麦考利久期、修正久期(年化)、凸性、DV01、应计利息。

组合分析：上传债券持仓 CSV（name,coupon,ytm,maturity,freq,face,market_value）或逐行录入 → 逐债指标 + 组合加权修正久期 / 凸性 / DV01(货币)。

收益率曲线：输入各期限点（3M/2Y/10Y/30Y）收益率 → 形态判定（陡峭/平坦/倒挂）+ 关键利差（10Y-2Y、10Y-3M）。

信用利差：输入信用债 YTM / 基准 YTM /（可选）PD、LGD → 信用利差、OAS、期望损失 PD×LGD。

利率压力测试：平行冲击 ±bp → 组合价值变动%（久期 + 凸性二阶修正）。

示例：10Y/票息3%/YTM3.5% 国债 → 价格 95.81、修正久期 8.53、凸性 83.78；+50bp 冲击组合价值约 −3.4%。

三大报表 / 比率 / 杜邦
支持：资产负债表 / 利润表 / 现金流量表；财务比率（流动比率、资产负债率、ROE、ROA、毛利率、净利率）；杜邦分析；雷达图；输入股票代码自动获取财报。

操作：输入股票代码 → 选报表类型 → 获取 → 看比率和图表。

3.16 DID 计量分析
双重差分政策评估
用途：面向政策评估的双重差分（DID）回归，论文级输出（Table 1-6 格式）。

变量设置：treatment（处理组）/ time（政策时点）/ outcome（因变量）/ 控制变量。

分阶段分析：
  ① 数据清洗与描述统计（Table 1）、相关性矩阵
  ② 基准 DID 回归（Table 2，支持逐步加控制变量 / 标准化系数）
  ③ 稳健性检验：平行趋势 / 安慰剂 / 子样本回归
  ④ 异质性分析：分区域 / 老龄化 / 城乡 / 收入
  ⑤ 机制分析：中介效应 / 交互项
  ⑥ 结果导出（论文 Ready 表格）

示例：长护险试点对家庭消费结构的影响（clean.csv）→「🚀 一键运行完整分析」。
💬
3.17 NLQ 自然语言查数
自然语言 → SQL → 图表
功能：用自然语言提问，自动生成 SQL 并执行（也支持数据库直连场景）。

使用：输入"统计各省份生存型消费占比平均值" / "2020 年城镇化率最高的 5 省" / "人均 GDP 与教育水平相关性" → 自动生成 SQL → 执行 → 结果 + 图表。

高级：置信度评估（低时反问澄清）、A/B 测试对比 Prompt、Bad Case 收集、反馈闭环（点赞/点踩）。
🔍
3.18 RAG 智能问答
知识库检索 + 引用来源
功能：上传文档（PDF/TXT/CSV）→ 构建知识库 → 智能问答。

使用：上传 → 自动分块向量化 → 输入问题 → 混合检索（BM25 + 向量语义）→ 答案 + 引用来源。

特点：本地 Embedding（bge-m3）零费用、中英混合、专名精确匹配。

3.19 报告生成
HTML / Word 导出
自动收集：各标签页生成的图表自动收集到报告面板。
模板：无模板 / 家庭照护研究 / EDA 探索性分析 / 金融分析。

导出：
  • HTML 报告：预览 → 选模板 → 下载
  • Word 报告：点击「📝 导出 Word」→ 用系统文件选择器自选保存路径与文件名（默认 data.tool报告_日期.docx），含标题/结论/图表/表格

操作：生成图表 → 切「报告」→ 选模板 → 生成 → 导出 HTML 或 Word。

3.21 AI 助手
对话分析 / 代码执行 / 建议闭环
打开：右上角「AI 助手」按钮或 Ctrl+Shift+A。

⚡ 双模式：
  • 快速模式：知识库命中秒回原文，未命中且是实时/行情问题再走 LLM 简短快答
  • 深度思考：知识综合归纳、聊天联网搜索、分析请求走 Agent 深度分析（真实调用工具）

📚 知识问答：直接问"什么是市盈率""LPR 是什么"→ 秒回知识点，自动标注「📚 知识点库」来源（覆盖 142 条金融/银行/税务/ML/固收知识点，见 3.35 知识点库）。

智能分析：自动感知顶栏选中文件 → 说"帮我分析当前文件"→ 自动执行描述统计 → 对话中展示结论并同步渲染到对应标签页；深度分析（Agent）自动调用 32 个真实工具生成结构化报告（核心结论/数据概况/分析发现/分析建议）。

🤝 多 Agent 并行协作：当请求是"全面分析 / 研究报告 / 尽调 / 完整评估"这类需要多视角的作业时，会自动进入多 Agent 并行管线——市场分析师、量化建模师、风控合规官三个阶段同时点火，各绑不同模型，最后由终稿合成统一交叉验证。请求只涉及单一职责时只跑命中的阶段（纯规则判定，不额外消耗 LLM 额度）。详见 3.32。

💡 建议闭环：分析完给出「建议操作」卡片 →「✅ 采纳并执行」自动执行网站功能并同步到报告页。

代码执行："画散点图分析 xx.csv 中 A 和 B 的关系"→ 生成 Python 执行（沙箱 30s 超时、模块白名单、禁文件操作）。

默认模型：日日新 GLM-5.2（1M 上下文、免费公测）。可在「AI 助手」顶部的模型下拉框切换 Provider / 模型（日日新 / 深度求索 / OpenAI 兼容 / 本地 Ollama）；多 Agent 管线的三个阶段模型可分别钉扎，例如 市场 glm-5.2 ∥ 量化 sensenova-6.8-flash-lite ∥ 风控 deepseek-v4-flash。

3.32 多 Agent 并行协作管线
三阶段并行 · 按需命中 · 终稿合成
是什么：遇到需要"多视角 + 多方法"的作业时，AI 助手不再由一个模型从头写到尾，而是派出多个专家 Agent 同时开工，最后由「终稿合成」把各方结论交叉验证、统一成一份报告。

三个专家角色与模型钉扎：
市场分析师宏观 / 行业 / 景气 / 估值视角 · glm-5.2
量化建模师数据 / 统计 / 建模 / 回测视角 · sensenova-6.8-flash-lite
风控合规官风险 / 合规 / 稳健性 / 压力测试视角 · deepseek-v4-flash
终稿合成交叉验证 + 统一成文（主模型，不参与轮换）

核心设计 ① · 并行不累加：三个阶段是同时点火而不是排队，总耗时 ≈ 最慢的那个阶段 + 终稿合成时间，不是三者相加。

核心设计 ② · 按需命中（不是每次都全跑）：由纯规则判定该叫哪几位专家，零额外 LLM 调用：
含「全面 / 完整 / 全方位 / 尽调」+ 分析类词三阶段全跑
只命中某个职责关键词（如"风控"）只跑命中的那个阶段
挂了数据文件、无明确职责补一位量化建模师
什么信号都没有保底只跑市场分析师

核心设计 ③ · 阶段间不传产出：三个专家各查各的，交叉验证统一交给终稿。若把上游产出喂给下游，并行就退化成了串行，反而更慢。

稳定性设计：每个阶段有独立会话隔离、独立取消与检查点，单个阶段失败 / 超时不影响其他阶段；失败（如模型限流 429）会被判定为降级而不是假成功——降级文本不会进入终稿，避免污染结论。阶段编号与进度提示随命中数量动态变化（只跑一个就显示 1/1）。

实测（三阶段全跑）：串行 435s → 并行 277s（提速约 1.57×）；三条阶段的启动时间戳落在 5 毫秒内，这是并行的直接证据。开启按需命中后：单阶段端到端 48s，三阶段 211s。

怎么用：无需任何配置。在 AI 助手里说"对当前文件做一次全面的研究报告"即自动触发；触发后到「🧭 Agent 流程」（3.33）就能看到三个节点同时亮起。

3.33 Agent 流程可视化画布
真实轨迹回放 · 节点状态 · 问题定位
位置：「🤖 AI 提效」组 → 🧭 Agent 流程；AI 助手顶栏的诊断入口也可进入。

是什么：把 AI 助手每一次问答的真实运行轨迹画成流程图——走了哪些节点、按什么顺序、各花多少时间、哪一步失败、失败原因是什么。不是示意图，是真实执行记录的重放。

怎么用：
运行记录下拉选一次历史运行回放；选「跟随最新一次运行」时，你每提一次问画布自动切到那一次
刷新列表重新拉取运行清单
重载画布保持当前选中运行重画
新窗口打开全屏查看，适合演示 / 投屏

看图要点：节点颜色 = 状态（成功 / 失败 / 跳过）；连线 = 数据流方向；多 Agent 并行时会看到多个节点同时开始，各自计时互不阻塞；出问题会把报错挂在对应节点上。

数据来源：由本站 /api/assistant/flowviz/* 同源接口直接读取轨迹文件提供，不依赖额外服务、不需要另开端口。

用途：① 排查"AI 为什么慢 / 为什么没出结果 / 到底哪一步失败"；② 给同事或面试官演示多 Agent 协作的实际形态。

小提示：画布页面体积较大，采用首次进入标签页才加载的懒加载策略，不影响站点首屏速度。

3.36 故障排查手册
症状 → 原因 → 步骤 · 9 类高频故障
位置：「数据接入」组 → 🔧 排查。

覆盖 9 类高频故障，每类给出「可能原因 + 分步排查路径 + 可直接复制的命令」：
🤖 AI 助手不返回结果模型是否已选 / Key 是否有效 / 网络是否通
🗄️ 数据库连接失败驱动缺失（pymysql / psycopg2）/ 凭证 / 端口 / 只读护栏拦截
🖥️ 页面空白或功能不显示浏览器 / Service Worker 缓存了旧 JS
🚀 服务启动失败 / 闪退端口占用 / 依赖缺失 / 残留双实例
📄 数据文件打不开 / 乱码 / 上传失败编码 / 格式 / 体积 / 安全校验拦截
📊 图表不显示 / 中文乱码字体缺失 / CDN 加载失败 / 图片未生成
⏰ 定时任务不执行调度器未启动 / cron 格式错 / 任务已停用
🃏 评分卡建模报错目标列非 0/1 / 样本太少 / 分箱不收敛
🕷️ 爬取无结果页面结构变化 / 反爬 / 选择器失配

怎么用：顶部输入症状关键词自动过滤 → 点「展开排查步骤」看完整路径。

通用三板斧（记这三条能解决大多数问题）：① 看日志——启动窗口的滚动输出即服务日志，结构化日志在 logs/；② 看接口——F12 → Network，失败请求看状态码与 error 字段；③ 重启生效——改过后端代码必须重启（重新双击 start.bat），改过前端 JS 后按 Ctrl+F5。

7 常见问题（FAQ）
启动失败，提示端口被占用？
关闭之前的命令行窗口，或任务管理器结束 python.exe 后重新双击 start.bat。
图表中文显示为方框？
已自动配置 Microsoft YaHei 字体。如仍有问题，确认 C:\Windows\Fonts 存在中文字体。
如何上传自己的数据？
「上传」→ 选 CSV/Excel → 自动检测编码导入，支持中文列名。
生成的图表在哪里？
静态图在 output/charts/，同时「报告」自动收集；交互图（Plotly）在「智能图表」查看。
如何切换深色/浅色主题？
右下角 🌙/☀️ 按钮，或 Ctrl+Shift+L，偏好自动保存。
请求被限流（429 错误）？
上传/训练/筛选等重操作有速率限制，等待 1 分钟后重试即可。
AI 助手没有自动分析？
先在顶栏下拉框选中数据文件，再对 AI 说"帮我分析当前文件"。
大盘/数据概览显示的是上一交易日？
数据源降级链：腾讯实时 → 新浪实时 → akshare → baostock 日线。受限时降级为日线并标注日期，KPI 卡片显示"实时·日期"或"收盘 日期"。
五因子模型运行很久？
需从 baostock 逐只拉行情与财务。30 只×1 年约 1-2 分钟属正常；可选 20 只或缩短区间至 6 个月。
北向资金为何没有数据？
2024 年 8 月起交易所停止每日披露北向净买入，仅南向（港股通）完整。资金流向图显示南向净买入。
知识库/多Agent 提示 404 / 未登录？
知识库、多Agent 等需登录。先「登录」注册/登录（默认 admin/admin123）再访问。
AI 深度分析报错 "Agent error"？
检查 LLM 配置：默认模型为日日新 GLM-5.2（免费公测），可在「AI 助手」顶部下拉框切换 Provider 与模型。若报错含限流（429）字样，属账户瞬时速率限制，等数十秒重试即可。确认当前 Model API Key 有效期与账户余额后重试。
怎么调用 API 接口？
登录后创建 API Key，请求头携带 X-API-Key: <key> 或 Authorization: Bearer <JWT>，返回 JSON。
固定收益分析怎么用？
「固定收益」标签页：单债输入票息/YTM/期限/付息频率得久期凸性；上传持仓 CSV 看组合加权久期；收益率曲线看形态与利差；信用利差看 OAS；压力测试看 ±bp 价值变动。
DID 回归结果如何解读？
关注交互项(treatment×time)系数与显著性(p 值)：显著为正说明政策提升因变量。先用「平行趋势检验」验证 DID 前提，再用「安慰剂/子样本」做稳健性。
NLP 情感分析准吗？
基于通用情感词典，对标准财经/评论文本效果良好；高度口语化或反讽可能偏差。建议结合分词统计与 TF-IDF 关键词综合判断。
如何查看审计日志？
用 admin 登录 →「安全中心」→ 查看系统状态与审计日志，数据库直连的每次查询/导出均留痕可追溯。
多 Agent 并行分析为什么比串行快？
三个专家阶段是同时点火而不是排队等待，总耗时 ≈ 最慢的那个阶段 + 终稿合成时间，不是三者相加。同口径三阶段全跑对照：串行 435s → 并行 277s（提速约 1.57×），三条阶段的启动时间戳落在 5 毫秒内。开启按需命中后，单阶段只要 48s、三阶段 211s。
顺带提醒：早前曾出现过一次 156s 的运行，那是假快——某个阶段被限流导致输出残废、终稿又被截断，产出不完整，不能当作正常耗时参考。
我提问后为什么只跑了部分专家？
这是按需命中的预期行为：只有含「全面 / 完整 / 全方位 / 尽调」这类全域请求才三阶段全跑；否则只跑与问题职责相关的阶段。判定走纯规则，不额外消耗 LLM 额度，也避免无关专家产出噪音。想让三位专家都上场，就在提问里明确说"全面 / 完整 / 尽调"。
某个专家阶段失败会怎样？
该阶段被标记为降级，其失败提示文本不会进入终稿（避免污染结论），其余阶段结果照常合成报告。失败节点与原因可在「🧭 Agent 流程」画布上直接看到。注意：模型限流（429）属瞬时限速，等待数十秒重试即可，不代表模型不可用。
「🧭 Agent 流程」画布上看不到运行记录？
先到「AI 助手」提一次问产生轨迹，再回画布点「刷新列表」。保持「跟随最新一次运行」时，之后每次提问画布会自动切到那一次运行；也可以用下拉框回放任意历史运行。
