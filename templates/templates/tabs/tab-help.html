📖 使用教程

一条主线贯穿全平台：取数 → 清洗 → 分析 / 金融 → 建模 → AI → 报告。 下面按左侧导航的 10 个分组，逐个模块给出「怎么做 · 关键字段 · 容易踩的坑」； 每个模块右上角可直接跳转过去。

1
先有一份数据 上传 CSV/Excel，或用金融行情、数据源、爬取、数据库直连取数。没有现成数据也能先把界面跑通。
2
处理与建模 清洗 → 统计图表 → 时序 / 因子 / 财报 / DID / 评分卡 → 机器学习。
3
问 AI / 出报告 AI 助手一句话分析、NLQ 查数、RAG 问答；结论与图表汇总到报告页导出。

❓ 常见问题

1开始

🏠数据概览一盘看清市场、文件与待办▾

怎么做

  1. 打开就是首页；左侧导航第 1 组里的这一项。
  2. 看四类卡片：市场行情（指数/资金流/汇率/情绪/异动）、任务、数据血缘统计、快捷跳转。
  3. 要干活时从这里直接点进对应模块，不必记路径。

关键字段

行数 / 文件
当前 output 目录里可分析的数据文件（含你上传的）。
任务队列
后台异步任务（爬取、训练等）的进度与结果。
血缘
每个产出文件由哪些步骤生成，可回溯。

容易踩的坑

  • 行情类卡片依赖外部数据源（akshare/tushare 等），断网时卡片会是空值但功能不受影响，别当成故障。
  • 「市场」卡片的涨跌颜色遵循 A 股习惯：涨红跌绿。
🧭智能流程不知道从哪开始，就让系统推荐一条路径▾

怎么做

  1. 在输入框里描述目标，例如「用 CSV 做预测建模」「看一只股票值不值得买」。
  2. 点推荐流程，按给出的顺序点过去；跑偏了点重置再来。
  3. 页面下方还有四块常驻说明：企业深析手把手、数据源导航、AI 助手能问什么、常见问题 FAQ。

关键字段

推荐流程
按关键词匹配出的模块顺序，含直达按钮。
重置
清掉当前推荐，回到初始态。

容易踩的坑

  • 推荐是按关键词的规则匹配，不是大模型推理：词太偏就命中不到，此时直接看本教程对应分组更快。
📤上传把本地表格变成可分析的数据▾

怎么做

  1. 把 .csv / .xlsx / .xls / .txt 拖到虚线框，或点击虚线框选文件（可多选）。
  2. 上传成功后，「已导入文件」区会立刻列出来；稍等片刻下方「选择要分析的文件」也会同步。
  3. 在「选择要分析的文件」里点一下文件名，它才会成为当前文件，后续分析页默认用它。

关键字段

已导入文件
本次会话可见的数据文件，含大小与修改时间。
选择要分析的文件
当前文件的选择器；勾选框用于批量删除/归档。

容易踩的坑

  • 上传完要再点一下文件名才算选中，否则后面的分析仍按旧文件跑。
  • CSV 用 UTF-8 保存；中文乱码时先在「清洗」页做编码转换。
  • 删文件是软删除（可恢复），但归档后默认不在列表里显示。
💾存储把结果落库、下载、查血缘、发只读链接▾

怎么做

  1. 存入数据库：把当前文件写进 SQLite，随后可下载 data.db 带走。
  2. 数据血缘追踪：输入文件名（如 clean.csv）点「溯源」，看它的上下游。
  3. 只读分享链接：填文件路径 → 生成链接 → 复制链接发给别人（只读）。

关键字段

表名 / 唯一键
入库时的表名与去重主键，重名会按唯一键合并。
血缘查询
支持相对路径（output/xxx.csv）与绝对路径。

容易踩的坑

  • 分享链接是只读的：打开的人只能看，不能改数据。
  • 若通过公网隧道分享，对方访问时需要登录或带 API Key（本机／局域网访问才免登录）。
  • 「下载 data.db」拿到的是整个库，不是单表。
🧩模板常用分析的预置起点▾

怎么做

  1. 在列表里挑一个贴近你目标的模板。
  2. 点一键使用，系统把模板要求的数据与参数带到对应模块。
  3. 列表有更新时点刷新重新拉取。

容易踩的坑

  • 模板只是「起点」：字段对不上时仍需手动改，尤其列名必须与你的表一致。
📄报告把整条链路的结论和图表汇成一份文档▾

怎么做

  1. 先在各分析页把有价值的结论/图表存进结论池（页面上通常有「保存结论」类按钮）。
  2. 到报告页核对「本次会话结论」「本次会话图表」两张清单。
  3. 点生成完整报告 → 预览 → 📝 导出 Word 或下载 HTML。

关键字段

结论 / 图表清单
决定了报告里会出现什么，生成前先核对。
导出 Word
可自选保存路径（Chrome/Edge 支持，其他浏览器降级为直接下载）。
下载 HTML
单文件 HTML，图文内嵌，方便直接发出去。

容易踩的坑

  • 报告内容来自「结论池」，没存过结论就会是空报告——这不是生成失败。
  • 清空全部不可撤销，导出前先下载一份留底。

2取数

🌐数据源可用的取数渠道一览▾

怎么做

  1. 用上方的搜索/筛选框缩小范围（按类别、是否免 Key 等）。
  2. 在「数据源列表」里选定一个源，按卡片上的按钮直达官网取数。

关键字段

六大分类
官方统计 · 金融行情 · 债券货币 · 开放数据 · 学术研究 · 企业深析（共 70+ 个数据源，支持关键词搜索）。
查「公司名」↗
先在「企业深析」里填好公司名，本页 13 个企业信源卡会出现「查『公司名』↗」， 一键打开该公司在巨潮 / 交易所 / 研报中心 / 企查查的检索页。
与金融行情联动
akshare / tushare / baostock / yfinance / FRED 五源行情在 「金融行情」页按分类下拉取数并存成 CSV。

容易踩的坑

  • 部分源需要外网或 Key；拿不到数据时先判断是"源不可用"还是"参数写错"，再看「排查」页对应条目。
  • 本页是导航页：它只负责把你送到对的官网/接口，取数动作在目标页完成。
💰金融行情多源取行情存成 CSV，也能用一句话生成 SQL▾

怎么做

  1. 取数：选数据源（akshare / tushare / baostock / yfinance / FRED）→ 填代码与区间 → 点对应的「获取」按钮。
  2. 结果会存成 CSV（如 raw.csv），随后到「金融可视化 / 因子回测 / 财报」继续用。
  3. Text-to-SQL：在自然语言框里写需求（如「统计上个月各省份的销售额」）→ 连接数据源 → 执行查询；也可切到「直接输入 SQL」自己写。

关键字段

股票代码
A 股 6 位（如 600519）；各源对后缀要求不同，报错先核对代码格式。
区间
起止日期决定 K 线/指标的跨度。
源
FRED 为宏观数据（如 RSAFS 零售销售额），需要外网。

容易踩的坑

  • tushare 需要 token，未配置会直接失败；先用 akshare（免 Key）。
  • 同一只股票在不同源的复权口径不同，跨源比较前先统一。
🕷爬取从网页抓表，落成 raw.csv▾

怎么做

  1. 填 URL 与页数；需要时填 CSS 选择器限定区域。
  2. 填要抓的字段（列名映射），需要翻页就填下一页规则。
  3. 点开始爬取，在「运行日志」看进度；完成后到「采集结果」下载 raw.csv。

容易踩的坑

  • 爬取是同步执行，「停止」只会在本次爬完后生效，不是立刻中断。
  • JS 动态渲染的页面抓不到内容：换静态页，或改用官方接口/金融行情。
  • 抓不到结果先看日志里的具体报错，再对照「排查」页的「爬取无结果」。
🗄数据库连外部库、用中文生成 SQL、留操作审计▾

怎么做

  1. ① 连接管理：＋新建 → 填参数 → 测试连接 → 保存。
  2. ② 智能 SQL 查询：写自然语言 → 🧠 生成并查询 → 核对生成的 SQL → ✅ 确认执行；不满意点 🔄 重新生成。
  3. ③ 操作审计：所有执行记录可查，点刷新审计。

关键字段

连接名
保存后供查询选择，建议写清库用途。
SQL 预览
生成后先看再执行，避免误操作。

容易踩的坑

  • 数据库访问走的是只读 SQL + 审计留痕，写操作会被拒绝——这是设计如此。
  • SQLite 路径被限定在 output/、uploads/、data/ 内，随便填盘符路径会被拒。

3清洗

🧹清洗把脏数据收拾干净，而且每一步都能撤▾

怎么做

  1. 先看诊断报告，点缺失值分析 / 生成热力图摸清数据问题分布。
  2. 在字段处理里按需操作：文本清洗、编码、日期标准化、批量替换、条件过滤。
  3. 点执行清洗 → 看「清洗完成」结果 → 下载 clean.csv。
  4. 做错了点撤销上一步；关键节点用📸 创建快照，之后可回滚到快照。

关键字段

缺失值填充
不处理 / 删除行 / 均值 / 中位数等，选错会改变分布。
快照
带血统的还原点，比"撤销"更耐用，可跨会话回滚。

容易踩的坑

  • 「删除行」会真的少数据，删完再算统计量就和原始样本不是一回事；要留痕就先建快照。
  • 清洗后的文件名是 clean.csv，后续分析记得在「上传」页把当前文件切过去。
🔢表格JOIN、加列、透视、抽样▾

怎么做

  1. 执行 JOIN：选主表/副表与关联键，选连接方式，看「JOIN 结果」。
  2. 生成新列：用现有列做运算或表达式，产出新字段。
  3. 透视表 / 交叉表：拖行、列、值，快速做汇总表。
  4. 执行抽样：抽取子集用于快速试验，最后下载 CSV。

容易踩的坑

  • JOIN 前先确认关联键的类型一致（"600519" 与 600519 不相等）。
  • 多对多关联会让行数膨胀，JOIN 后先看行数是否符合预期。
🔍筛选按条件从全市场筛标的▾

怎么做

  1. 设置筛选条件（估值、涨跌幅、市值等）。
  2. 点开始筛选，在「筛选结果」里看命中标的。
  3. 满意就导出 CSV，随后进「金融可视化 / 因子回测」。

容易踩的坑

  • 条件叠加越多命中越少，结果为 0 先放宽一个条件再排查。
  • 筛选用的是外部行情，非交易时段/断网可能返回空。

4统计

📈分析描述统计、相关性、分组，大文件走 DuckDB▾

怎么做

  1. 描述统计 / 相关性：选列 → 点对应按钮，结果直接出表。
  2. 数据分组：选分组列与聚合列，得到分组汇总。
  3. 文件很大时用⚡ 快速统计（DuckDB）：点「刷新引擎状态」确认可用，再「▶ 执行查询」。

容易踩的坑

  • 相关性只对数值列有意义，文本列会被忽略或报错。
  • 相关系数高≠因果，尤其时间序列会有伪相关，结论前先看「时序」页的平稳性检验。
📊图表推荐合适的图，并顺带给一句洞察▾

怎么做

  1. 点生成图表 + 洞察：系统按列的类型与分布推荐图形，并给文字解读。
  2. 需要可缩放/悬浮提示时点🕹 渲染交互图表（Plotly）。
  3. 把满意的图保存进结论池，报告页会带上它。

容易踩的坑

  • 类别太多（如几百个城市）时柱状图会糊，先按「筛选/表格」聚合再画。
  • 图表是静态图片时不能交互，要交互就用 Plotly 那条路径。
🔬假设检验t / ANOVA / 正态性 / 分布拟合▾

怎么做

  1. 选检验类型与列（分组对比要指定分组列）→ 点执行检验。
  2. 用均值对比图 / 正态拟合曲线 / 分组箱线图看图形证据。
  3. 需要存档就点导出报告。

关键字段

p 值
小于 0.05 通常称"显著"，但要看效应量是否真有意义。
正态性
决定该用 t 检验还是非参数检验。

容易踩的坑

  • 样本量很小时正态性检验本身不可靠，别只看 p 值；必要时用非参数方法或先看箱线图。
  • 多组两两比较要校正多重比较，否则假阳性会明显变多。
📉时序平稳性 → 分解 → 建模预测▾

怎么做

  1. 提取特征 / 重采样：先把时间列规整到统一频率。
  2. 执行检验（ADF）判断是否平稳——这是能不能直接建模的前提。
  3. 分解看趋势/季节/残差，再点建模预测（Prophet 或 ARIMA 按提示选参）。

关键字段

时间列
必须是可解析的日期时间，否则先到「清洗」页做日期标准化。
p,q,d
ARIMA 阶数；不确定就让系统按 AIC 挑，别硬调。

容易踩的坑

  • ADF 不显著（非平稳）就不要硬套模型，先差分。
  • 外推越久误差越大：中短期预测可用，长期外推要谨慎。

5金融

📉金融可视化K 线、多股对比、联动图▾

怎么做

  1. 选图形与标的，点生成选中图表；想一次全出就点生成全部。
  2. 需要交互缩放用生成交互图表；要看相对强弱用生成对比图（多股）。
  3. 多图联动看趋势一致性，用加载联动图表。
  4. 要留着归档，点📦 批量导出 HTML。

容易踩的坑

  • 颜色遵循 A 股：涨红跌绿，和国际习惯相反，别误读。
  • 图依赖已取到的行情 CSV；先确认「金融行情」页已经把数据取下来了。
💹因子回测CAPM / 五因子 / 策略回测▾

怎么做

  1. 运行建模取基础数据；再分别做 CAPM 分析 / 运行五因子模型。
  2. 运行回测检验策略表现，用评估对比横向比较多个模型。
  3. 满意的模型点保存，之后加载预测复用。

关键字段

Alpha / Beta
Beta 衡量对市场的敏感度；Alpha 是剥离市场后的超额。
超额收益 / 回撤
回测报告里最该看的两个数，比单看收益率更接近真实体验。

容易踩的坑

  • 回测好不等于未来好：参数调出来的高收益往往是过拟合。
  • 对比多个模型时注意样本区间是否一致，否则结论不成立。
📑财报三表 + 比率 + 杜邦 + DCF 估值▾

怎么做

  1. 填代码 → 获取财报数据。
  2. 计算财务比率，并在杜邦分析里看 ROE 的三段拆解（净利率 × 周转率 × 权益乘数）。
  3. 切利润表 / 资产负债表 / 现金流量表核对原始数字。
  4. 计算 DCF 估值，最后点开始对比分析和同业/历史比。

关键字段

ROE
拆开看更靠谱：是靠赚钱能力，还是靠加杠杆。
DCF 参数
自由现金流增速、WACC、净负债、股本——对结果影响极大，别用默认值直接下结论。

容易踩的坑

  • DCF 对假设极其敏感，同样的公司换个增速结论能翻倍：把它当"敏感性参照"而不是"目标价"。
  • 财务数据来自外部源，口径（合并/母公司、单季/累计）要先确认。
🏢企业深析输入公司名，跑完一整套公司研究▾

怎么做

  1. 输入公司名 → ⚡ 开始自动分析（想跳过 AI 用快速（不用 AI），结果更稳更快）。
  2. 等「分析漏斗」8 个阶段跑完，看「分析结果总览」的六大板块。
  3. 用计算 + 排雷扫描看风险信号；用一页纸判断卡 →看浓缩结论。
  4. 导出：导出 Word / 导出 PPT / 导出 JSON。

关键字段

公司档案（分析后校正）
行业、市场、日期、分析人等字段会写进 Word/PPT 页眉——但必须在分析完成后改。
护城河六维
技术/品牌/渠道/成本/网络/牌照，0–10 分。
草稿来源
状态里会写明是 AI 还是规则草稿；AI 失败会降级成规则稿并标提醒，不用重跑。

导出与留存

导出 Word / PPT
PPT 有 5 套模板：商务深蓝（默认）、科技深色、增长青绿、简约汇报、投研备忘录。
结果存在哪
存在浏览器本地（localStorage）——换浏览器或清缓存会丢失，重要结论请导出留存。
A 股 / 港股
A 股的行业规模、增速、市占率、CR3/CR5 自动填充（东财营收口径）； 港股的行业聚合数据免费渠道暂无，页面会提示需人工从研报补充 —— 属数据源限制，不是故障。

容易踩的坑

  • 在「公司档案」里启动分析前填写是无效的——流水线会用抓到的数据覆盖，改完再跑才生效。
  • 耗时受外部数据源影响：A 股常见几十秒，接口慢时可能到一两分钟。卡住时看阶段状态，别重复点。
  • 结论里出现"需人工核实"属正常：模型被要求不得编造数字，缺数据时宁可留白。
  • 提示「财报接口无数据」是自动降级：可用字段照常填充、缺失字段留空并在阶段进度里标黄，稍后重跑一次即可。
📈基金业绩指标、净值 CSV 计算、指标速查▾

怎么做

  1. ① 按代码取数：填基金代码 → 计算指标（年化收益、波动、夏普、最大回撤等）。
  2. ② 净值 CSV 计算：上传自己的净值序列 → 用 CSV 计算指标。
  3. ③ 指标速查：不确定某个指标含义时查这里。

关键字段

夏普比率
每承担一单位波动换来多少超额收益，越高越好，但需同口径比较。
最大回撤
历史最深的净值跌幅，直接对应持有体验。

容易踩的坑

  • 比较不同基金时，区间必须一致（短区间的高夏普往往不可持续）。
  • 净值要用复权/累计净值，用单位净值算会把分红当亏损。
💵固收久期凸性、曲线、利差、压力测试▾

怎么做

  1. ① 单债计算器：填票面、期限、价格 → 计算单债指标（久期/凸性/YTM）。
  2. ② 组合分析：加多只债与权重 → 计算组合，得加权久期与凸性。
  3. ③ 收益率曲线：+ 添加期限点 → 分析曲线，看形态（正常/平坦/倒挂）。
  4. ④ 信用利差 / OAS：计算利差评估信用补偿。
  5. ⑤ 利率压力测试：设定利率冲击 → 运行压力测试。

关键字段

久期
利率变动 1% 时价格的大致变动幅度（近似）。
凸性
修正久期的非线性补充，波动大时不可忽略。
倒挂
短端利率高于长端，常被当作衰退信号之一。

容易踩的坑

  • 久期是近似线性的：利率大幅变动时必须叠加凸性，别只用久期估。
  • 压测结果是"给定情景下"的估计，不是预测。

6计量风控

📊DID 双重差分评估一项政策到底有没有效果▾

怎么做

  1. 变量设置：指定处理组标识、时间列、结果变量、控制变量；点 🔄 刷新列 重新读列名。
  2. 🚀 一键运行完整分析 跑全流程；也可单独跑某一步（描述统计 / 相关性 / 基准回归 / 逐步加入控制变量 / 标准化系数 / 平行趋势 / 安慰剂 / 子样本 / 异质性 / 中介 / 交互项）。
  3. 在 6. 结果输出 汇总导出实证结果。

关键字段

处理组标识
必须是 0/1（或可转成 0/1）的列。
交互项系数
Treat × Post 的系数就是 DID 估计的政策效应。
平行趋势
政策前两组走势应大致平行，这是 DID 成立的前提。

容易踩的坑

  • 平行趋势不通过，DID 的结论就不成立——先看这一步再解读系数。
  • 安慰剂检验若也显著，说明可能只是共同趋势，不是政策效果。
  • 面板数据要确认"个体×时间"唯一，重复行会让结果失真。
💳评分卡WOE/IV 分箱 → 打分 → PSI 监控▾

怎么做

  1. ① 数据与参数：加载列 → 指定目标列（0/1 违约标识）与特征 → ② 训练评分卡。
  2. 用🔍 分箱预览逐特征看 WOE/IV 与单调性，必要时调整分箱。
  3. ③ 评分卡结果看 KS/AUC；💾 保存模型、📄 导出 PDF 报告。
  4. ④ 应用评分卡 对新数据打分；⑤ PSI 监控跟踪线上分布漂移。

关键字段

IV
单变量预测力，常用经验区间：<0.02 弱、0.1–0.3 中、>0.5 需怀疑泄漏。
KS / AUC
模型区分度；KS 常看是否 >0.3，AUC 常看是否 >0.7。
PSI
群体稳定性，常用阈值 0.1 / 0.25 分档判断漂移程度。

容易踩的坑

  • IV 高得离谱（>0.5）通常是特征泄漏（用到了未来信息），不是模型强。
  • 分箱单调性不成立的特征，业务解释会很别扭，优先手动调分箱而不是硬上。
  • 训练样本里"好客户"远多于"坏客户"时，别用准确率评估，看 KS/AUC。

7建模

🧠机器学习训练、调特征、评估、管版本▾

怎么做

  1. 模型训练：刷新列 → 选目标列与特征 → 开始训练；不确定选哪个算法时点加载分类目录看场景推荐。
  2. 特征工程：时序特征 / 交叉特征，或一键全部 → 执行特征工程；用 🔍 计算 Spearman 看与目标的相关性。
  3. 模型评估面板看指标；模型版本管理里加载版本列表、对比所选两版本。
  4. 模型预测 对新数据出结果；需要扩展能力时在🧩 分析插件上传并校验。

关键字段

目标列
分类还是回归由它的类型决定，选错指标会全错。
特征
含 ID/时间戳之类唯一值列会严重过拟合，先剔掉。

容易踩的坑

  • 别用全量数据训练后又在同一批上评估：留出验证集（或看交叉验证结果）才可信。
  • 类别不平衡时"准确率 99%"可能是全猜多数类，改看召回/AUC。
📝NLP 文本分词、情感、关键词、词云、文档问答▾

怎么做

  1. 选文本列（必要时先刷新列表）→ 点开始分析。
  2. 看分词统计 / 情感分析 / TF-IDF 关键词 / 词云四类结果。
  3. 要针对某份文档提问，用文档问答（指定知识库文档） → 智能问答。

容易踩的坑

  • 情感分析对领域词很敏感（金融/医学语境常判错），结果当趋势看，别当结论。
  • 文本列里有大量空值会拉低词频统计的意义，先在「清洗」页处理缺失。
⛓Pipeline把多步分析串成一条可复用的流水线▾

怎么做

  1. ＋ 新建流水线 → 进「编辑流水线」。
  2. ＋ 添加节点，把清洗/分析/训练等步骤连成 DAG。
  3. 💾 保存 后点 ▶ 运行；换了数据源可直接重跑复用。

容易踩的坑

  • 改完记得先保存再运行，否则跑的仍是旧版本。

8AI

🤖AI 助手用一句话驱动取数、分析与出图▾

怎么做

  1. 直接在输入框描述需求，如「看一下当前文件的相关性并画图」「帮我跑一遍评分卡」。
  2. 左侧 ⚡ 快速 / 🧠 深度 切换档位；旁边下拉可切模型。
  3. 需要上下文时：＋ 新会话、📷 传图片；跑偏了点 ■ 停止（会通知后端取消，别硬等）。
  4. ⚙️ 打开设置（含数据出境开关面板）；🩺 / 🧭 看诊断与流程；🧩 Skills 技能 可导入 zip 或直接粘贴 SKILL.md。

关键字段

⚡ / 🧠
快速档更快更省；深度档会多轮推理，慢但更细致。
上下文条
显示当前文件与所在页，AI 会据此理解"这个文件/这一页"。
出站提示
涉及联网/外部调用的能力会在这里提示可用状态。

可以直接这样问

  • 问公司：「腾讯股价多少」「佰维存储现在估值贵不贵」「帮我深度分析五粮液」—— 别名表外的新公司也能自动识别；后两类会分别触发行情估值与企业深析工具。
  • 问行业：「茅台所在行业的规模和 CR3 是多少」→ 行业聚合工具（规模 / 增速 / 市占率 / 集中度）。
  • 查资料：「帮我查一下贵州茅台的研报 / 招股书 / 有没有诉讼」→ 按信源检索公开资料，返回标题与链接。
  • 做分析：上传 CSV 后问「分析当前文件，做个描述统计」「两列相关性如何」→ 调用站内分析工具并落表落图。

容易踩的坑

  • 没选文件就问"这个文件怎么样"，AI 无从下手：先在「上传」页选中文件。
  • 很慢或没结果时不要反复重发，先看 🧭 流程诊断 定位是哪一步卡住。
  • AI 给出的数字仍属"草稿结论"，关键指标请回到对应分析页复核。
🤝多 Agent把复杂任务拆给多个角色协作▾

怎么做

  1. 在创建协同任务里写清目标，点创建任务。
  2. 在任务列表看进度与结果，点刷新列表更新。
  3. 要看每个角色做了什么，用执行链路追踪。

容易踩的坑

💬NLQ 查数用中文问数，确认 SQL 后执行▾

怎么做

  1. 点刷新数据源确认能连上的库。
  2. 输入问题（如「按省份统计上个月销售额」）→ 🧠 生成 SQL。
  3. 先看生成的 SQL，确认无误再点 ✅ 确认执行；不满意点 🔄 重新生成。
  4. 历史查询在「查询历史」里，可复查。

容易踩的坑

  • 系统不会给你编造的数据：答不上来时是明确报错，而不是编一行"看起来合理"的结果。遇到报错请调问题或检查数据源。
  • "先生成再确认"是刻意设计：避免改一次问题就把 SQL 悄悄换掉。
🔍RAG 问答基于你的知识库回答问题▾

怎么做

  1. 确认要问的知识库已经在「知识库」页建好并传了文档。
  2. 在输入框提问 → 点提问，答案会带出处。
  3. 答非所问时，换更具体的问法或补充关键词再问。

容易踩的坑

  • 库里没有的资料它答不出来——先补文档，而不是反复追问。
  • 问句太笼统会稀释检索效果，把关键实体写进问题里。
🧭流程诊断AI 慢/没结果时，看它到底卡在哪一步▾

怎么做

  1. 在轨迹列表里选一次运行（刷新列表更新）。
  2. 看画布上的阶段顺序、耗时与失败标记，定位慢在哪、错在哪。
  3. 需要细看就新窗口打开。

容易踩的坑

  • 看到某阶段标红再谈"AI 不行"：多数情况是取数超时或模型返回格式问题，重跑往往就好。

⏰定时任务让取数/分析按时自动跑▾

怎么做

  1. ＋ 新建定时任务：填名称与执行周期（Cron 表达式），点创建任务。
  2. 在任务列表里启用/停用、查看⛓ 依赖、需要时▶ 立即运行试一次。

🛠故障排查按症状找原因，覆盖 10 类常见故障▾

怎么做

  1. 在搜索框里输入症状关键词（如「页面空白」「端口占用」「爬取无结果」）自动过滤。
  2. 点展开排查步骤看该症状的完整处理路径。
  3. 实在定位不到，先练「通用排查三板斧」那一节。

覆盖的症状

  • AI 助手不返回结果 / 数据库连接失败 / 页面空白或功能不显示
  • 服务启动失败或闪退 / 数据文件打不开、乱码、上传失败
  • 图表不显示或中文乱码 / 定时任务不执行 / 评分卡建模报错 / 爬取无结果

容易踩的坑

  • 改了前端代码后必须 Ctrl+F5 硬刷新，否则看到的是缓存的旧 JS/CSS，会误判成"没生效"。
👤登录 / API Key谁能访问、怎么带凭证▾

怎么做

  1. 登录 / 注册：本站默认已有一个管理员账号；需要多人使用时在「注册新账号」里加。
  2. 用户中心：看自己的信息、配额，退出登录。
  3. 给脚本调用时用 API Key（在请求头里带）；带错/过期的 Key 会直接返回 401。

关键字段

免登录范围
本机与同一局域网访问免登录（自动按管理员身份处理），所以手机连着同一 Wi-Fi 直接打开就能用。
公网访问
通过隧道暴露到公网时必须登录或带有效 API Key，匿名请求会被拒绝（401）——这是安全设计，不是故障。

容易踩的坑

  • 手机打不开：先确认与电脑在同一网段，且服务是以 0.0.0.0 启动的（不是只绑 127.0.0.1）。
  • 公网分享给别人后对方 401，属预期行为，让对方登录即可。

❓ 常见问题

Q：公司识别不了？▾
  • 支持任意 A 股 / 港股公司名（会自动联网核对证券简称），也支持 6 位、5 位与 HK+4位 代码。
  • 行业分析类句子（如「分析新能源汽车行业」）不会被误当成个股。
  • 仍识别不出时，改用股票代码最稳。
Q：企业深析的行业数据是空的？▾
  • A 股的行业规模 / 增速 / 市占率 / CR3 / CR5 会自动填充。
  • 港股的行业聚合数据免费渠道暂无（页面有明确提示），需人工从研报补充 —— 这是数据源限制，不是故障。
Q：提示「财报接口无数据」？▾
  • 外部数据源临时不可达时会自动降级：能拿到的字段照常填充，缺失字段留空并在阶段进度里标黄。
  • 稍后重新跑一次通常就好，不必反复点。
Q：企业深析的结果存在哪？换电脑还有吗？▾
  • 存在浏览器本地（localStorage）：换浏览器或清缓存会丢失，换电脑不会带过去。
  • 重要结论请用「导出 Word / PPT」留存。
Q：AI 回答里为什么写「仅供参考」？▾
  • 涉及投资 / 财务的结论都会注明「客观数据分析，不构成投资建议」，导出到 Word / PPT 的报告页脚也会带这行 —— 合规要求。
Q：AI 很慢 / 没有结果？▾
  • 先去「🧭 流程诊断」看这一次跑到哪一步、哪一步标记失败，再决定重跑还是改问法。
  • 多数情况是取数超时或模型返回格式问题，换 ⚡ 快速档或重跑一次即可。
  • 别反复重发：后台仍在跑，重复请求会叠加消耗。
