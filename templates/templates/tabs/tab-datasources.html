站内已有的数据获取能力
  • 金融数据 tab — 站内已接入 AkShare / Tushare / Baostock / yfinance / FRED 五源： 覆盖 A 股／港股／美股行情、全球指数与外汇、美债收益率、基金净值与持仓、债券收益率、期货、指数， 以及 中国宏观（GDP/CPI/PPI/PMI/LPR/社融/M0-M2） 与 美国宏观/利率（FRED：失业率/CPI/非农/利差/SOFR）、 三大财务报表、资金流向、融资融券与限售解禁等，按分类下拉即可直接拉取并存为 CSV。
  • yfinance — 免 token 拉美股/港股/全球指数/外汇/美债收益率与新闻； FRED — 美国宏观与利率序列免 token 下载，也可设环境变量 FRED_API_KEY 启用官方检索。
  • 接口目录 API — 访问 /api/finance/catalog 可获得完整数据源清单（含分类与参数说明）， 也可让「AI 助手」直接按自然语言调用这些接口取数。
  • 筛选器 tab — 一键获取全市场 A 股财务指标并按条件筛选。
  • 企业深析分类 — 与「企业深析」tab 的信息收集清单一致（招股书 / 年报 / 巨潮 / 交易所 / 投资者关系 / SEC EDGAR / 企查查 / 裁判文书 / 知产局 / 研报 / Wind / 行业协会）。 先在「企业深析」里填好公司名称或代码，本页即出现「查该公司」按钮，一键直达该公司在各信源的检索页；在「企业深析」里还可点「获取信息」由后端自动检索并写入摘录。
  • 本页列出的站点适合获取行业、企业、专利、国际等站内未覆盖的数据；下载 CSV 后可回到「上传」tab 导入分析。
